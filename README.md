# Dois Toques

Jogo mobile (PWA) de um toque só por vez: metade esquerda da tela avança para a esquerda, metade direita avança para a direita. Não caia nos buracos e não deixe o chão que desaba te alcançar.

Protótipo v0.1 — a forma da grade (losango, hexágono, tijolo) ainda está em teste e pode ser trocada no menu.

Rodar localmente: `python3 -m http.server` na raiz e abrir `http://localhost:8000`. Testes: `npm test`.
